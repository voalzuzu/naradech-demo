# นราเดช เลี่ยมกรอบพระ — ระบบจัดการงาน

ระบบจัดการงานสำหรับร้านเลี่ยมกรอบพระ — บันทึกงาน ติดตามสถานะ และคำนวณราคา

## Live Demo

[เปิดระบบ →](https://voalzuzu.github.io/naradech-demo/naradech.html)

## ฟีเจอร์

- บันทึกรับงานใหม่ (ชื่อลูกค้า, ประเภทงาน, วันกำหนดส่ง)
- คำนวณราคาและติดตามการชำระเงิน
- แสดงสถานะงาน (รับงาน / กำลังทำ / เสร็จแล้ว)
- รองรับการใช้งานบนมือถือ

## วิธีใช้

เปิดไฟล์ `naradech.html` ในเบราว์เซอร์ หรือเข้าผ่าน GitHub Pages link ด้านบน

## Tech Stack

HTML · CSS · JavaScript (Vanilla) — ไม่ต้องติดตั้งอะไรเพิ่ม
